# Volk Security Systems Website

This project was created for ITEC 3020.

I chose Option B, which is a company landing page. The website is based on a home security company called Volk Security Systems.

## Pages

The website includes:

- Home
- About
- Services
- Products
- News
- Contact

## Features

The website includes:

- Responsive design
- Light and dark mode
- Shared header and footer
- JSON file-loaded blog posts
- Product and news search filters
- Contact form validation
- Mobile navigation

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
